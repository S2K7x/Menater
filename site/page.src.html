A · What it is 01 Premise

Every other console sells automated confidence. This one sells legible restraint.

An LLM triaging security alerts is reading text an attacker composed. So the question is not how much the model can decide — it is what the system does when the model, the data, or the network is wrong. Four rules answer that, and they are enforced in code rather than promised in a slide.

Never fill a gap with a default

A missing value is shown as missing — —, never 0, never N/A, never a guess. And rejecting an alert because a field is absent is the same mistake in its harshest form: it replaces the alert with nothing.

The two-tier alert contract

Silence is never consent

An approval request that times out executes nothing — it escalates. Missing configuration cannot enable execution either: shadow mode is the default, and only the exact string false turns it off.

The approval flow · shadow mode

A failure must never show green

A chain that ran and passed zero items is Broken, not Done. A verdict of clean requires at least one intelligence source that actually answered — nobody looking is Not asked, which is a different sentence.

The Tracking tab exists only for this

No irreversible action without a human

The action catalogue is closed at four entries. Nothing else is implementable — not even behind an approval — and no tuning rule can reach it. The console has a database; it executes no security action on its own.

server/engine/transforms/domain.ts

Nothing here is invented, and the console tells you what it does not know.

A · What it is 02 Two halves

One interface, two tenses.

SOC — what has happened

Alerts arrive from a SIEM, get normalised against a two-tier contract, deduplicated, enriched from threat-intelligence sources, put to a model, and routed. Every run is written to a hash-chained audit log. Shadow mode records the decision and executes nothing until a team has measured its own disagreement rate.

Postgres · six workflows · built-in engine

VulnPipe — what is about to

Code analysis on the same screen. Tree-sitter indexes routes and call graphs, a deterministic scanner and a local model score each address, and only the grey zone — a confidence between 0.4 and 0.7 — costs an arbitration call. Every finding carries a plain-language summary: what can happen, and how to fix it.

IDOR · XSS · SQLi · security misconfiguration

Merged: the interface. One build, one lock, one theme. Not merged: the engines. The analyser stays a service of its own, because pulling tree-sitter and the model SDKs into an API that has exactly one production dependency would buy nothing.

B · How it works 04 Pipeline

Six workflows, typed at every handoff.

MENATER runs its own engine. No n8n, no workflow platform, no second product that has to be reachable for an alert to be triaged — so a workflow cannot be half-deployed, renamed in an editor, or left unpublished. The console reads its own run journal.

01 Ingestion Validates identity fields, deduplicates, and answers the sender what actually happened — 400, 200 already seen, or 202 accepted.
02 Enrichment Reputation, geolocation, ATT&CK tagging. A source with no key is not asked, and the model has to name it.
03 AI Decision The verdict, its confidence, and its reasoning. With no model key: needs_human, confidence 0. Fail-safe, never fail-open.
04 Action / Routing Approval requested in Slack or Discord. Below the notification threshold, nobody is asked — so nothing waits, and it escalates.
05 Audit Log One append-only row, sealed into a hash chain under an advisory lock. Immutable by design.
06 · ERROR HANDLER Declared as the native error workflow on the other five, and called only from their failure branches — never in the normal sequence. No failure is ever silent: every branch logs, notifies, or both.
What that costs the engine 3 consequences
  • A junction waits A node with several upstreams does not start when one has answered. Enrichment would otherwise assemble a third of its sources — with no error, no trace, and a plausible result.
  • Retry, then a named failure Every external call retries with exponential backoff and full jitter, honouring a suggested Retry-After as a floor. A route that was not analysed is not a healthy route.
  • The unreduced view The queue stitches runs into cases; two failure shapes disappear in that reduction. The Tracking tab shows them unreduced — broken chains, runs attached to no alert, a searchable log, and replay that refuses when the original payload is unknown.
B · How it works 05 Ingestion

Push and pull fail differently, so the default uses both.

A critical contained four minutes late was not contained; a low triaged four minutes late is still a low. So the hybrid policy sends P1 and P2 down the webhook and polls P3 and P4 — and an alert whose severity did not survive normalisation takes the fast lane, because quietly parking something that might be a critical is the failure this product exists to make impossible.

TierFieldsRule
Identity alert_id · rule_name · severity · timestamp · raw_log Required. Missing means rejected — and the rejection names the fields.
Observables source_ip · dest_ip · user · host · process · file_path · url Optional. Absent stays absent: null, never an empty string, never invented. Most real detections carry no destination address.
Extensions everything else Kept whole, on the case and in the audit row. Nothing your tool sends is discarded.
The four rules the transport obeys 4 rules
  • Nothing is refused for taking the wrong lane A P4 on the webhook is accepted and triaged; the reply carries a block saying which transport the policy expected. Dropping a detection over a routing preference replaces it with nothing.
  • The cursor moves onto delivered data only Not onto data we read, and never after an empty or failed poll — a source that is down looks exactly like a source where nothing happened. With no cursor at all the poll looks back further than the gap between two polls, so consecutive windows always overlap.
  • A poll that placed nothing is a failed poll The HTTP call succeeding is not the question. It says how many alerts it read, how many it placed, and names the cause when those differ.
  • The route decides the mapping Alerts arrive at POST /api/ingest/<source> — never the payload, so a sender cannot claim to be something else. The Wazuh integration maps nothing: it forwards the alert as written and the console translates.
C · What holds 06 Refusals

The list of things it will not do is the feature.

Four closed catalogues, each closed for the same reason: an operator points this console at attacker-composed text all day, and an open list is an instruction away from being someone else's.

CatalogueSizeWhat being closed prevents
Actions 4 isolate_host_temporary (TTL, auto-revert), ticket, escalate, auto_close. Isolation refuses to run when it has no host to name: an action whose target is unknown is not an action.
Assistant tools 7 getters The in-console assistant can read the queue, an alert, a chain, the rules, the metrics, health and setup state — and write nothing. An injected instruction arrives at a model holding seven getters. That is the layer that holds; the fencing and the system prompt come after it.
Credentials named list Both key stores accept only names on a fixed list. An arbitrary name would turn the settings endpoint into a way to inject any environment variable into the process, PATH included.
Intel providers 7 sources The lookup endpoint takes a value and a kind — never a URL. A route that fetched what it was handed would be a request forgery with a button on it.

Shadow mode by default

Decisions are recorded, none are executed, until the false-positive rate has been measured over at least 50 alerts. The gate is human_disagreement_rate — the share of decisions a human rejected — not the share the model called false positive. One measures correctness; the other measures distribution.

Untrusted text is fenced, never deleted

Log content travels inside markers carrying a per-request nonce, so a log cannot forge a closing tag for a marker that did not exist when it was written. Nothing is stripped: rewriting evidence is the same mistake as filling a gap with a default.

Tuning rules have limits

A team can declare what is normal here — the authorised scanner, the backup window. The console refuses a permanent allow keyed on one identity field alone, a suppression with no expiry, and any rule with no owner or no reason.

C · What holds 07 Measured

Numbers, with the conditions they were taken under.

Run against docker compose up — Postgres, console, code analysis, and nothing else. These are a QA pass on one machine, not a published benchmark; the point is that they are reproducible and that the conditions are stated.

400 / 400 alerts accepted 50 concurrent · ~134 alerts/s · p95 424 ms · every chain settled, nothing left running
1 of 12 duplicates accepted 12 simultaneous copies of one alert id → 1 accepted, 11 already seen, zero errors
0 broken links in the audit chain ~500 rows written at 40-way concurrency after the sealing fix; re-verified across 2,644 rows
1,278 tests passing 913 console · 365 code analysis · typecheck clean

Eight defects were found by that pass and fixed, three worth naming: the entry point told senders their refused alerts had been accepted; the deduplication insert was not race-safe and answered 500 under a burst; and the audit verifier reported broken links on healthy rows, because row ids were allocated outside the sealing lock. A verifier that cries wolf is one an auditor stops believing — which would hide a real deletion in the noise.

C · What holds 08 Design

Six themes. Contrast is tooled, never judged by eye.

Every theme redefines the entire palette — inheriting three tokens produces an accident invisible on review. A test computes the WCAG ratios and refuses a palette: 4.5:1 for text on every surface, for text laid on the accent, and for the risk colours inside their own pills. It caught a failure red at 2.5:1, on the screen that depends on red most.

The switch in the header is not a mock-up: it repaints this page with the console's six real palettes, from the same token set. Colour never carries meaning alone — every risk colour is paired with a word.

One accent, one job

The accent designates exactly one thing: a human is blocked here, and the primary action. Red says critical or failed, orange worth a look, green handled. A red button would teach an analyst to ignore red on the one screen where red saves time.

The mark is the first principle

Five ticks, the middle one a stub rather than a full bar — a missing value keeping its place instead of being omitted. Absence sits at the centre, so the mark stays symmetric: the gap is the composition, not a defect in it.

Density is a feature

The triage table is meant to show forty rows. Mono means this string came from the machine, and it is exact; prose about a value is sans, the value is mono. An analyst scrolling is an analyst who has lost the overview.

D · Getting it 09 Install

Three commands, on any host.

Docker is the normal installation mode, not an option. No Node to install, no Postgres to configure, no schema to apply by hand, no third machine. The database and the analyser are reachable only from the compose network — a second entry point would be a lock protecting half the application. 

# fill in the two passwords
cp .env.example .env

# postgres + console + code analysis
docker compose up -d --build

→ http://localhost:4400

The stack comes up in three minutes and triages nothing. That is not a fault: each of the four things below is a choice the console refuses to make for you, and the checklist at the top of Settings tracks all four until they are done.

#WhatIf you skip it
1A shared ingestion secretThe endpoint stays closed whatever mode you pick — here an empty secret closes the door rather than opening it.
2Open the door: ingestion mode PrimaryEvery alert is refused.
3A model keyEvery alert takes the fail-safe verdict: needs_human, confidence 0. Nothing is lost; nothing is triaged.
4A log sourceNo alerts arrive.

Enrichment keys and chat notifications are optional. A missing enrichment source is shown as Unavailable rather than filled in. One profile is off by default — --profile tunnel — because a service you do not know you started is a service you are not watching, and that one opens a door to the Internet.

D · Getting it 10 Not yet

What it does not do.

Stated here for the same reason the console states it: a page that only lists what works is a green that was never earned.

  • The two halves do not talk A code scan creates no case in the triage queue, and an alert triggers no scan. The merge is currently visual — one interface, one lock, one build — and closing that gap is the priority that outranks the others.
  • The lock identifies nobody Access is a single password. It protects access; the approver's identity stays self-declared, and the audit row says exactly that rather than implying an identity it does not have.
  • Autonomy is gated on measurement Leaving shadow mode is not a switch to flip early. It waits on a disagreement rate measured over real alerts that went through the real guardrails — comparing a case the pipeline did not produce yields disagreements that are not disagreements.
